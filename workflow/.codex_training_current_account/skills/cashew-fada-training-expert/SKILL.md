## Sequence

1. **Initialize.** Verify the supplied starting checkpoint profile and source/unlabelled evidence. Explain the likely adaptation bottleneck and the expected response to the starting controls. Retain a conditionally useful pretrained module. Inspect local and global alignment, class conditioning, and the inference BN state as appropriate.
2. **Acquire every five completed epochs when automatic annotation is enabled.** The worker screens the fixed, geographically varied AEF imagery frame and reports how many candidates remain in each category. Choose how many new cases to resolve in each category. Review prior acquisitions and exposure so repeat cases have a reason. Early requests often justify six to ten newly resolved cases; later requests can vary, including zero. Include concentrated Cashew-versus-tree or crop competition and diffuse three-/four-class indecision where present. Use a small bidirectional miss/extra-Cashew audit and an occasional broad check when useful. Confidence, class competition and geographical context suggest cases to inspect.
3. **Wait for intake.** The acquisition plan leaves the completed epoch unchanged. The job releases its training GPU while the installed `cashew-sample-assist` judges dated high-resolution imagery, or while the isolated simulator supplies test cases. Outcome records distinguish imagery skips, processing failures, valid pixels and coverage of the actual hard area. A valid same-period original-grid annotation can be reused. The next decision is made after intake closes, with the count and reason for any shortfall. The worker evaluates the current model on the new valid masks before the first supervised update.
4. **Tune after intake.** Source segmentation and accepted visual supervision both use four-class cross-entropy. The label values are 0 crop and other, 1 mixed trees and wetland/water, 2 Cashew, and 3 built-up. The worker masks 10 and invalid AEF pixels, separately normalizes the auxiliary loss, and uses target inference BN stats for its supervised forward with full gradients. The initial example weight is 0.5. The weight controls update strength; repeat count controls exposure. Check the effective auxiliary-to-source gradient ratio and direction alongside the actual measured fit. Severe sign imbalance, one dominant land unit, or a conflict with the source should be interpreted alongside class and spatial response. Use an executable matched trial when the diagnosis hinges on it and when the allocated horizon can reveal the mechanism.
5. **STOP.** Judge expected marginal reduction in comparable losses across meaningful intervals. Separate source validation loss, source training loss, and fit on the same previous-library masks with the same decoder. A changed auxiliary weight or harder incoming batch affects the total loss. Inspect actual exposure, preserved source function and plausible remaining benefit before deciding. A small, noisy annotation library supports diagnosis; it supplies no automatic STOP threshold. A waiting label batch is an intermediate state. A cap is a budget endpoint.
6. **SELECT.** After STOP is committed, compare the eligible frozen inference states, including E0 and important alternatives before and after interventions. Retrieve `candidate_details` for E0, the chosen checkpoint and the strongest alternative, and cite the available `annotated_training` evidence for each. The worker evaluates one frozen annotation library using identical valid masks and target BN with four-class argmax. Check which labels each model had already seen and read both error directions. Incorporate source and unlabelled behavior, module movement and intervention responses. Explain tradeoffs or missing measurements. Checkpoint identity freezes before external point evaluation.
