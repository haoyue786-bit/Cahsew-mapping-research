# Google Earth integration

The [Google adapter](../scripts/imagery/google.py) and its browser tool acquire the current and historical views. Follow the [image selection rules](imagery-selection.md). Each new sample retains the registered RGB, visible historical dates, capture attribution, control points and coverage mask.

The earlier implementation is archived in `outputs/cashew_google_browser_fix_20261116` for reproducing prior runs. Use the current selection entry point to acquire imagery for a new sample.
