# Sol source-image annotation

Judge the full date-qualified RGB and return one short SAM2 prompt plan. Classes are 0 crop/other, 1 confirmed other woodland, scrub, open savanna, wetland or water, 2 Cashew, and 3 built. Use auxiliary checks only when they could decide a specific unit. The total allowance per AEF tile is ten, including any used on a previous image of this tile. A wider landscape, original detail, reviewed appearance examples, country background or numbered proposal boxes are available. Stop as soon as you have enough evidence.

Inspect the primary RGB first, including visibly different canopy interiors, edges and both sides of roads. Request a local crop or reviewed example when it can resolve a specific doubt. For planted rows of small dark crowns, compare a Mix tree reference with `appearance=rows` alongside an appropriate Cashew reference. Use the wider landscape or regional background when the scene's surroundings or local lookalikes matter. If the operator supplied observations matched to this exact RGB, inspect those locations too. Retain high-confidence negative units with visible land-cover evidence.

When using another date to confirm a woody class, check the same crowns for local cloud, haze and heavy shadow. Count that view as corroboration only when the crowns are visible and it reveals a distinguishing feature at the marked location. If the available views show only a dense, lookalike canopy, mark its identity uncertain.

For each confirmed unit return its class, one or two interior positive points, any useful negative points in the adjacent canopy, and a tight enclosing box if a point alone could spill into other cover. Use integer XY in the complete source image. Points must be within 0–1023. A box uses left, top, right, bottom edges within 0–1024. The host requests one mask per unit from SAM2, checks it against the prompts and exports automatically.

For every class 2 unit, fill `cashew_evidence` with one brief observation explaining what distinguishes these crowns from other trees at the same site. Compare nearby woodland under similar light and check whether the change in relative tone and crown texture persists across several crowns or follows a visible parcel edge. A close reference can guide the comparison. If Cashew and Mix tree remain equally plausible, inspect an eligible alternate date or dry view when available. Leave unresolved units as 10. For other classes set `cashew_evidence` to null. Use `whole_cashew_evidence` only when assigning class 2 to the entire tile.

Prefer verified local dry imagery whenever proposing Cashew. On a usable non-dry view, report supported other cover and set `needs_dry_season` when woody identity remains ambiguous. The host automatically looks for a dry view if you propose class 2 on this image. With a non-dry primary and no qualified dry view, use `view_comparison` when available to verify a supported Cashew candidate on another date. Confirm class 2 only where the same location shows convincing contrast on both dates. Cite the comparison image and briefly describe each date's cue. Class labels and SAM2 coordinates refer to the primary input RGB.

Start by identifying which classes the full footprint supports. Use `whole_class` only when one class is confirmed across the footprint, with `regions=[]`. For screened scenes with two clear classes, follow the background rule in the screened-scene guide. Outline any remaining mixed or unresolved areas. The host assigns class 10 to uncertain areas and any areas left without a supported class. List auxiliary image IDs only when actually viewed and used. Keep qualified dry scenes. If a scene is unusable and the schema allows replacement, request an in-window replacement.
